# 师徒关系修正

relationship-corrections.json 仅包含人物姓名和待增删关系，不含账号、密码哈希或密钥。

在包含对应人员的数据库上应用：先停止服务并归档数据库副本，在项目根目录运行 `node scripts/apply-relationship-corrections.cjs`，再启动服务。设置了 DB_FILE 时使用该数据库，否则使用项目的 database.json。

脚本只新增缺失人物和关系、删除明确指定的边，不删除人物或其他师傅。重复执行不会重复创建；所有师傅匹配并通过 DAG 校验后才保存，保存前更新最近一次有效备份。

运行数据库及自动备份仍属于本地数据，不应与修正文件一起提交。此文件不替代数据库备份。
